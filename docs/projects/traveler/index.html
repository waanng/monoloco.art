ART PROJECT / 旅行摄影

旅行者。

留在照片里的记忆碎片

旅行中的随拍，是留给自己的记忆碎片。街口、站台、猫和水面的涟漪，不一定指向一个地标，却能让人重新想起到过那里的感觉。

LZ点击作品，放大观看 ↗

照片留下的，是“曾经在那里”。

有时，记忆不是按地点排列的。它可能是一家店面前的人，一条巷子里遇到的猫，或一次在水边停留的片刻。

这些影像不急着讲完一段旅程。让彼此无关的画面相邻，也让那些偶然的相遇继续发生。

图文整理自《忽独》第一期，影像与原文分别保留作者署名。
