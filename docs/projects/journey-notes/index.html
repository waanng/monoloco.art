我们仨。

一家人的出游与陪伴

我们仨，是一家人在路上的记录。走进不同的城市，在街边休息、一起吃饭、追着气球奔跑。照片留下彼此陪伴的片刻，手绘地图串起一起走过的路。

王安点击作品，放大观看 ↗

一直在路上，可以相互依靠。

一直在路上，追逐奔跑，坐下来休息，对视微笑。未来的路还长，可以相互依靠。

从海岸、公园和校园，到街巷、书店和展厅，我们把旅行过成一家人共同的日常。镜头里的两个人，与镜头后的那个人，一起构成“我们仨”。

地图记下路线，照片记下相处。不急着列出每一个目的地，更想留下那些走在一起、停在一起的时刻。

照片与地图选自《我们仨》原始素材，序言摘自同名家庭影集。摄影与记录：王安。
